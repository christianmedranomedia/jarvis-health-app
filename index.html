JARVIS Personal Health

A private, single-user integration with the Oura API

JARVIS is a personal home dashboard that runs on one computer owned by its only user. With that user's own Oura authorization, it reads their Oura sleep summaries so the dashboard can show how they slept.

What it is

  • Personal use only. It isn't a product or a service, and it isn't offered to anyone else. There are no other users, accounts or sign-ups.
  • Read-only. It requests only Oura's daily scope and never writes to, changes or deletes anything in Oura.
  • Local. Data is stored on the owner's own computer and viewed only on the owner's own devices. It isn't sent to advertisers, data brokers or AI services, and it's never sold or shared.
